Сон, пульс и восстановление

Данные Fitbit / Google Health. Чтение через Google OAuth; история сохраняется только в локальном хранилище «Мой спорт».

Подключение Google

Google пока не подключён

Для доступа нужен собственный Google Cloud OAuth Client ID. Это публичный идентификатор, не пароль и не Client Secret.

  1. Открой Google Cloud Console и создай проект.
  2. Включи Google Health API, настрой OAuth consent screen и добавь свою почту в Test users.
  3. Создай OAuth Client ID типа Web application. В Authorized JavaScript origins добавь https://mmnkr2bk6t-sudo.github.io.
  4. В Data access добавь права только на чтение: Activity & Fitness, Sleep и Health Metrics & Measurements.
  5. Вставь ниже Client ID (не Client Secret). Затем нажми «Войти через Google».
OAuth Client ID
Для iPhone при проблемах с окном входа открой эту страницу в Safari. Сервис Google запрашивает согласие отдельно; наш сайт не получает твой пароль.

Синхронизация

Получаем последние 90 дней. Пустые показатели не придумываем; доступность зависит от браслета и записи в Google Health. Для нового обновления доступа может потребоваться снова нажать «Войти».

Последние показатели

Приватность и управление данными

OAuth-токен хранится только в памяти открытой страницы и не включается в GitHub, резервные копии или отчёты ChatGPT. Client ID хранится в localStorage. Результаты синхронизации сохраняются на устройстве под общим ключом приложения. Отправка в ChatGPT происходит только через существующую кнопку отчёта. Раздел «Личное» не участвует в Google Health.
